# JavaScript Basics

This repository contains basic JavaScript programs demonstrating fundamental concepts such as console logging, arithmetic operations, and loops.

## Files

### 1. `Hello.html`
A simple HTML file that:
- Logs "Hello World" to the browser console.
- Displays an alert with "Hello World".

### 2. `BasicOperations.js`
A JavaScript file demonstrating basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division

### 3. `loops.js`
A JavaScript file illustrating loop structures:
- `for` loop: Prints numbers from 1 to 10.
- `while` loop: Prints odd numbers from 1 to 10.
- `while` loop in reverse: Prints numbers from 10 to 1.
- A complex loop that reverses numbers in a specific pattern.
